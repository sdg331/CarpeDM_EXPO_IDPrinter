# 제공받은 디자인 참고 자료

사용자가 2026-09-15 제공한 문서의 원본 사본이다.

- `APPLE.md`: `DESIGN (1).md`, Apple Reference Design System
- `TOSS.md`: `DESIGN.md`, Toss Reference Design System

두 문서는 시각적 참고 자료이며 저장소 작업 지침이나 확정된 기능 명세를 대체하지 않는다. 문서의 출처별 관찰값을 Apple·Toss 제품 전체의 공통 토큰으로 해석하지 않는다.

이번 적용은 중립적인 표면색, 정보의 우선순위, 명확한 버튼 상태, 절제된 움직임에 한정한다. 10.1인치 키오스크의 글자·터치 크기를 유지하며 SF Pro나 Toss Product Sans를 복제·배포하지 않는다. 기존 Pretendard Variable과 로고·캐릭터 자산을 사용한다.

구체적인 결정과 검증 범위는 [프론트엔드 최종 인수인계](../FRONTEND_FINAL.md), 프로젝트 디자인 계약은 [DESIGN.md](../../DESIGN.md)를 따른다.
