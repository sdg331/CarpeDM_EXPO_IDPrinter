# K-FACE 평가 준비 상태 — 2026-10-11

사용자 지정 저장소 https://github.com/k-face/k-face_2019 를 내려받아 확인했다.
확인 커밋: b23304fbad696769bc7a6b3a886d9a0ecff6c235.
실제 인물 ID가 붙은 K-FACE 이미지 데이터는 저장소에 없다. image 폴더는 설명용 그림이며 samples는 학습 코드다.
README Download the Data에 가입·이미지 신청 후 별도 다운로드가 필요하다고 명시되어 있다.
공식 제공 페이지: https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=83

K-FACE 실사 매칭 평가는 아직 실행하지 않았다. LFW 결과를 K-FACE 결과로 간주하지 않는다.
assets/prototypes.npz와 운영 보정은 변경하지 않았다.
현재 scripts/evaluate_lfw.py는 LFW 인물 폴더를 가정하므로 K-FACE에 그대로 적용하면 안 된다.
공식 dataLoader.py 구조: 해상도/인물ID/Sxxx/Lx/Exx/이미지.
원본 확보 후 실제 파일명·폴더·정면 조건을 확인하고 인물 단위로 보정/평가를 분리한다.
고정 촬영 조건의 인물별 선택 집중도와 같은 인물의 조명/표정/각도별 선택 일관성을 별도로 집계한다.
성별/연령 평가에는 실제 메타데이터가 필요하며 얼굴 외관으로 속성을 추정하지 않는다.
결과에는 실패 수, 평가 인물 수, 캐릭터 선택 비율과 근접 점수 비율을 기록한다.
정답 캐릭터가 없으므로 닮음 정확도 측정으로 표현하지 않는다.

진행에 필요한 입력: 다운로드/압축 해제한 K-FACE 데이터의 로컬 폴더 경로.
