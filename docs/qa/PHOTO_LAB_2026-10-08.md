## 구현 범위

- `/static/photo-lab.html`에서 사진/휴대폰 촬영 파일 선택, 카메라 미리보기·촬영, 확대/이동, 3:4 프레이밍과 PNG 저장.
- `KIOSK_PHOTO_LAB=1`을 명시한 로컬 서버만 기존 YuNet/GrabCut의 배경·구도 정리를 처리. 새 얼굴·옷·정장 생성 없음. 기본 API 비활성.
- 원시 이미지 요청 8 MiB·기존 디코딩 전 1,200만 픽셀 제한. multipart/임시 파일/프로필 저장소/SQLite/장치 API로 사진을 보내지 않음.
- 선택한 사진은 브라우저 메모리에서 처리하며 배경 버튼을 누를 때만 같은 출처의 로컬 서버에 프레이밍 PNG를 전달. 페이지의 실제 테스트용 사진은 기존 공개 캐릭터에 브라우저에서 여백을 넣은 예시뿐이다. 파일명·실제 사진·사진 바이트를 로그에 기록하지 않았다.
- 정장 생성 미구현과 제공자·비용·사진 전송/보관 동의 미결정을 UI와 문서에 표시.
