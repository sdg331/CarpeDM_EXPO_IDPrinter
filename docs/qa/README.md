## 홈·팀 팝업 최종 정리 · 2026-10-05

대상 작업본은 `CarpeDM_EXPO_IDPrinter-complete`, 실제 확인 주소는 `http://127.0.0.1:8002/`이다. 기존 미커밋 변경을 보존하고 홈·공통 팀 팝업·상태 안내의 표현만 다듬었다.

- 홈: 상단 브랜드 한 개, 60px 환영 제목, 문구와 버튼 사이 44px. 출근·퇴근 버튼은 기존 704×144px 및 세로 배치를 유지한다.
- 제작 표기: 20px. 상단·하단의 얇은 구분선으로 화면의 영역을 정리했다.
- 장치 안내: 정상 흐름에서는 `장치 상태` 팝업에 표시한다. 서버 연결 실패 안내와 샘플/웹 미리보기 표시는 유지한다.
- 팀 팝업: 모든 팀의 세 업무를 나란히 놓고 키워드를 바로 아래에 묶었다. 800×1280에서 기획팀 높이는 749px → 약 637px이다.
- 접근성: 52px 닫기 버튼(작은 웹 화면 48px), 배경 입력 차단, 팝업 닫기 후 선택 카드로 포커스 복귀를 확인했다. 상태 버튼의 접근 가능한 이름은 실제 표시 문구와 일치한다.

## 팀 카드 가독성 재조정 · 2026-10-05

앞선 압축 시안의 작은 키워드·구역 제목과 평평한 업무 목록을 수정했다. 기존 팀 데이터·투명 PNG·로컬 Pretendard·모션·세션 흐름을 유지한다. [토스 TDS Button](https://tossmini-docs.toss.im/tds-mobile/components/button/)의 주요 행동과 보조 행동 구분을 참고했으며, 글씨·카드·팝업 수치는 키오스크용으로 정했다.

| --- | --- |
| 800×1280 여섯 팀 | 팝업 약 773~812px, 화면 안에 표시, 가로 넘침 없음 |
| 데스크톱 글씨 | 팀명 48px, 설명·업무·키워드 26px, 구역 제목 24px |

| 행동 | 전체 폭 입사 버튼 104px / 글씨 32px, 배경 없는 보조 행동 64px / 글씨 24px |

| 모바일 글씨 | 설명·업무·키워드 20px, 입사 버튼 72px, 닫기 버튼 48px |
| 접근성·이동 | 배경 입력 차단, 닫기 후 원래 팀 카드에 포커스 복귀, AI팀 → 이름 입력 전달 |
