# 8명 증명사진 정렬 및 흑백 출력 자산 · 2026-10-08

- 기존 8명의 얼굴을 입력으로 built-in image_gen에서 정면 자세, 밝은 배경, 증명사진 구도로 개별 편집했다. 01 편집본은 나머지의 구도 참고만 제공했다.
- 생성본의 미세한 기울기와 크기 차이는 기존 YuNet 눈 좌표로 정렬했다. 양쪽 눈은 폭의 40%/60%, 높이의 40% 기준이며 얼굴 형태를 비등방 변형하지 않는다. yaw/pitch 및 identity 보존은 육안 검토이며 정밀 3D 검증을 의미하지 않는다.
- 컬러 원본 1086×1448, WebP 192×256, 출력 288×384 1비트를 같은 편집본으로 갱신했다.
- 밝은 배경의 눈·코·입과 재킷 윤곽을 보존하기 위해 출력 기본 대비를 1.8 → 1.2로 낮췄다. gamma=1.15 유지, 최종 크기에서 Floyd–Steinberg 디더링한다. 이 값은 화면 시안 기준이며 실물 농도 확정값이 아니다.
- scripts/build_prototypes.py로 새 컬러 원본의 8×128 기준 벡터를 재생성했다. 독립 스타일 표본은 미확보 상태로 유지한다.
- frontend/js/content.js 및 참조 모듈의 이미지 버전을 20261008-idphoto8-r1로 변경했다. 기존 작업 중이던 UI 변경은 보존했다.
- 원본/출력/기준 데이터 백업: 상위 completion-backups/portraits8-before-idphoto-20261008/assets/.
- 결과 및 정확한 프롬프트: 상위 output/portraits8-idphoto-20261008/. build.py는 raw 편집본에서 정렬을 재현한다.
