# 분석 화면 연출 개선 · 2026-10-12

사용자 요청: 사진 위의 반짝임보다 AI가 분석하는 느낌을 강화한다.

SCR-09의 촬영 사진을 유지하면서 반복 스캔 라인, 연결된 포인트 그래픽, 모서리 프레임을 추가했다. A 모드에는 현재 8명의 WebP 미리보기와 순환 하이라이트를 표시한다. 이는 실제 순위나 분석 단계가 아닌 연출이며 화면에도 설명한다. 작은 웹 화면에서는 사진을 정사각형 영역에 담아 비교 목록이 얼굴 아래쪽을 가리지 않도록 했다. 사진은 원래 비율을 유지하고 `object-fit: contain`으로 표시한다.

주요 파일: `frontend/js/views.js`, `frontend/styles/kiosk.css`, `tests/frontend/kiosk.test.mjs`. `app.js`/`ui-preview.js`와 HTML 두 곳의 캐시 참조를 `20261012-analysis-r2`로 갱신했다. 웹 정적 분석 미리보기도 샘플 표시를 유지하도록 수정했다. 화면 정의·상태·인수 기준·디자인·결정 기록 및 README를 동기화했다.

기존 사진 Blob 해제, 요청 취소, 최소 6초 표시, 오류 즉시 안내, 세션/선택/출력 계약은 유지한다. API·모델·캐릭터 자산·감열 출력은 수정하지 않았다. 외부 라이브러리나 애니메이션 타이머를 추가하지 않고 CSS/SVG 및 기존 이미지로 구현했다.

## 실제 확인

- `npm test`: 최종 60 passed, 0 failed. 기존 분석 테스트를 확장해 스캔/연결망/8개 캐릭터, 샘플 표시, B 모드의 비교 목록 제외, 오류 시 효과 제거를 검증했다. 사진 해제·지연·취소·방문자 격리 테스트도 통과했다.
- `node --check`: 변경한 views/app/ui-preview JS 통과. `git diff --check` 통과.
- 800×1280 키오스크 정적 분석 화면: 사진과 8개 미리보기 로드, 가로 넘침 없음, 상태 안내가 화면 영역 안에 표시됨. 스캔/연결망/비교 애니메이션 이름과 적용 상태 확인.
- 390×844 웹 정적 분석 화면: 정사각형 사진, 샘플 라벨, 한글 줄바꿈, 8개 미리보기 로드, 가로 넘침 없음. 웹 화면은 스크롤을 지원한다.
- 샘플 클릭 흐름: 이름/팀 입력 → 촬영 → AI 오류 → 효과 제거와 재시도 안내 → 재촬영 → 분석 → 결과. 결과에 입력 이름/팀이 유지되고 분석 효과는 0개다. 실제 카메라·AI 입력의 실행 증거는 아니다.
- 브라우저가 reduced-motion 미디어 규칙의 `animation-name: none !important`를 정상 파싱하는 것을 확인했다. 실제 OS 설정 전환과 Pi 프레임률은 이번에 확인하지 않았다.

캡처는 수정하지 않은 브라우저 화면이며 실제 관람객 사진이 아니다.
