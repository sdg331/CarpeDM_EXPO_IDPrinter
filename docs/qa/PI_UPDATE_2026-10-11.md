# Raspberry Pi 업데이트 및 실행 오류 확인 · 2026-10-11

- 작업 브랜치 `feat/pi-latest-20261006`을 `origin/main`의 `0c66339`까지 fast-forward했다.
- 기존 카드별 테스트 기록 수정을 stash에 보관한 뒤 다시 적용했다. 최신 출력 복구, 화면 로딩 상태, 스타일과 테스트 기록 기능을 함께 유지하도록 네 파일의 충돌을 해결했다. stash는 복구용으로 유지한다.
- `KIOSK_PRINT=disabled`가 알 수 없는 백엔드로 표시되던 문제를 수정했다. 비활성 상태를 명시하고, 미리보기 생성이나 장치 접근 없이 재시도 가능한 출력 불가 오류를 반환한다. 기존 `.env`의 장치 설정은 유지한다.
- 최신 캐릭터 원본으로 인쇄 자산 및 얼굴 비교 데이터를 현재 Pi 환경에서 다시 생성했다. 업데이트 직후 기존 생성물과 로컬 계산 결과의 차이로 실패하던 두 자산 검증이 통과했다. 원래 생성물은 `/tmp/idprinter-before-local-asset-rebuild-20261011`에 임시 백업했다. 원본 초상 사진은 변경하지 않았다.

현재 프린터 출력은 운영 설정에 따라 비활성화되어 있다. MirrorTing URL과 bridge token이 설정되지 않아 실제 리포트 서버는 연결되지 않았다. 실제 카드 태그·카메라 촬영·실물 인쇄는 이번 자동 점검에서 수행하지 않았다.
