# 프론트엔드 최종 인수인계 · 2026-09-15

## 완료 범위

800×1280 세로, 10.1인치 키오스크용 입사·퇴근 프론트엔드를 마무리했다. 기존 FastAPI와 연결되는 순수 HTML/CSS/JavaScript 구조를 유지한다. NFC·프린터·AI B·MirrorTing 리포트의 실제 서비스 구현은 다음 연동 단계다.

실행은 Node.js 20 이상에서 `npm start`, 확인 주소는 `http://localhost:4173/?demo=1`이다. 설치나 빌드 과정 없이 동작한다. 체험 모드는 실제 장치를 작동시키지 않으며 고정 샘플임을 화면에 표시한다.

## 최종 디자인

- 홈: 행동을 설명하는 큰 제목, 평면 사원증 예시 하나, 세로 입사·퇴근 버튼. 인물의 비중과 그림자를 줄이고 겹친 카드·장식 문구·검증되지 않은 예상 소요 시간을 제거했다.
- 팀: 6개 팀을 짧은 소개가 있는 카드로 비교한다. 상세는 소개·키워드 카드와 주요 업무 카드로 나누며 확정 원문을 유지한다.
- 색: 흰 바탕, 중립 회색 표면, 진한 본문. 블루는 브랜드·주 행동·현재 상태에 집중한다. 반복적인 파스텔 타일과 강조를 줄였다.
- 서체: 로컬 Pretendard Variable. 본문 28px, 보조 안내 24px, 제목 52px, 홈 제목 60px. 주요 버튼은 32px 글자와 최소 104px 높이다.
- 입력: 포커스와 유효하지 않은 입력을 테두리·문구로 함께 알린다. 1~10자와 한국어 IME 처리 규칙을 유지한다.
- 촬영 오류: 원인과 복구 방법을 표시하고 재연결을 주 행동으로 제공한다. 감지되지 않은 얼굴이나 여러 명이 있는 상태에서는 촬영할 수 없다.
- 처리: 실제 처리 단계의 문구, 비활성화된 로딩 버튼, 회전 표시를 사용한다. 숫자 진행률과 장치 성공을 만들어내지 않는다.
- 완료·리포트: 완료 체크는 한 번만 움직인다. 리포트는 큰 본문과 내부 스크롤, 고정 출력 버튼을 유지한다.

홈의 사원증은 **디자인 예시**다. 실제 감열 인쇄는 기존 배지 렌더러를 사용하며, 인쇄 폭·단색 변환·행사 브랜딩은 장치 연동 때 실물로 맞춰야 한다.

## 움직임과 접근성

아래 수치는 이번 키오스크에서 정한 값이며 Apple·Toss의 공식 공통 모션 토큰이 아니다.

| 동작 | 적용 |
| --- | --- |
| 버튼 | 누를 때 120ms / 0.985배, 놓을 때 220ms |
| 화면 이동 | 280ms, 12px 수평 이동과 짧은 투명도 전환. 뒤로 이동은 반대 방향 |
| 홈 초기화 | 160ms 투명도 전환. 이전 화면의 개인정보를 복사하거나 남기지 않음 |
| 모달 | 배경 160ms, 내용 240ms 진입, 닫힘 140ms |
| 완료 | 360ms 체크 표시, 반복 없음 |
| 모션 감소 | CSS 애니메이션·전환·버튼 축소를 끄고 JS 화면 이동을 생략. 설정 변경 중인 효과도 취소 |

이동이나 요청은 효과가 끝나기를 기다리지 않는다. 같은 화면에서 NFC 등 상태만 갱신할 때는 화면 진입 효과를 재생하지 않는다. 빠른 연속 이동은 이전 효과를 취소한다. 닫히는 모달은 즉시 입력·포커스 대상에서 제외하며, 취소된 효과도 모달을 제거한다.

유휴 45초에 경고, 60초에 초기화한다. 경고는 `계속하기` 또는 `처음으로 돌아가기`로 조작한다. 배경 터치나 Tab 키로 갑자기 닫히지 않는다. 계속하기는 이름과 현재 단계를 보존하고 포커스를 복구한다. 완료 화면은 15초 후 초기화한다. 작업 중·결과 불명 상태의 초기화 제외 정책은 유지한다.

## 검증

- `npm test`: 17개 통과. 기존 세션 격리·작업 중복·오류·카메라 정리 13개에 연속 전환·모션 감소·모달 종료/취소 4개를 추가했다.
- 800×1280 브라우저: 홈, 팀 선택과 6개 상세, 이름, A/B 안내·촬영·처리·결과, NFC, 발급, 퇴근 조회·리포트·출력·완료, 점검 화면 확인. 검사한 주요 버튼의 잘림·가로 넘침·48px 미만 터치 영역 없음.
- 이름: 공백만 입력 및 11자 차단, 앞뒤 공백 제거, 10자 한글 결과 표시 확인.
- 오류: 카메라 연결 오류 후 재연결, 얼굴 없음·다중 인원 촬영 차단, AI 재촬영, NFC 등록 및 프린터 재시도 확인.
- 기록: 미등록 카드와 기록 없음에서 복구 안내 확인. 기록이 없을 때 리포트가 생성되지 않음.
- 리포트: 마지막 내용까지 스크롤하면서 출력 버튼 유지 확인.
- 실제 모드: 미구현 카드 연결이 성공으로 넘어가지 않고 연결 준비 안내를 표시함.
- 유휴: 경고에서 Tab 이동 후에도 경고 유지, 계속하기 후 이름과 입력 포커스 복구, 자동 초기화 확인. 설정창 연속 열기·닫기도 확인했다.
- 모션 감소: JS 단위 테스트와 CSS 분기 검토로 확인. 브라우저 도구에서 OS 모션 설정을 바꾸는 기능은 제공되지 않아 실제 Pi 설정 전환 검증은 남겨둔다.

이번에는 백엔드와 API 계약을 변경하지 않았다. 기존 Python 테스트 14개는 초기 구현 당시 통과했으며 이번 UI 변경에서 재실행하지 않았다.

## 다음 연동 단계

`frontend/js/live-integrations.js`에 AI B, 카드 등록/조회, 사원증/리포트 출력, 체험 기록 조회를 연결한다. 필수 반환값과 작업 ID 정책은 [구현 상태](IMPLEMENTATION_STATUS.md)의 실제 연결 계약을 따른다.

현장에서는 Pi Chromium의 물리 키보드 IME·터치·카메라와 ACR1252U·ZTP-80USL2, 실제 패널 배율과 시청 거리, 용지·중복 출력·통신 단절을 확인한다. 화면 체험 성공을 하드웨어 운영 검증 완료로 취급하지 않는다.
