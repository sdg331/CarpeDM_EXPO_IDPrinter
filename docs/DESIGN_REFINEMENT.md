# 팀 소개 카드와 디자인 정리 방향

2026-09-15 사용자 피드백: 팀 소개를 카드로 정리하고, AI가 만든 듯한 인상을 줄이는 방법 검토.

## 현재 화면에 대한 판단

화이트·블루 자체보다는, 큰 둥근 버튼·파스텔 아이콘 타일·겹쳐진 사원증·AI 생성 인물·추상적인 환영 문구가 함께 반복되는 구성이 범용 서비스 템플릿처럼 보이게 한다는 판단이다. 이는 시각적 평가이며 사용자 취향에 따라 달라질 수 있다.

## 이번에 적용한 팀 화면

- 선택 카드: 팀 이름 → 짧은 소개 → 소개 보기. 6개 팀은 2열·3행으로 한 화면에 표시한다.
- 상세: 소개와 키워드를 담은 카드, 주요 업무 3개를 담은 카드로 구분한다.
- 팀 이름·상세 설명·업무·키워드는 확정 내용을 유지한다. 선택 화면용 요약만 추가했다.
- 그림자와 파스텔 아이콘 상자를 덜어내고, 단색 아이콘·얇은 테두리·작은 모서리로 정보 구분을 명확히 한다.
- 상세 설명은 28px, 선택 카드 소개는 24px. 전체 카드 터치와 기존 확인 단계를 유지한다.

2026-09-15 최종 작업에서 1~3의 방향을 홈·AI 선택·촬영·결과·완료 화면에 반영했다. 홈은 평면 예시 한 장과 작은 인물, 행동 중심 제목을 사용한다. 실제 인쇄 레이아웃의 정확한 복제는 장치 연동 단계로 남기고 `사원증 디자인 예시`로 표시한다. 무늬만 있는 바코드, 반복되는 반짝임 아이콘, 추상적인 태그, 겹침·회전 장식을 제거했다.

버튼·화면·완료 피드백을 짧게 연결하고 모션 감소 설정을 지원한다. 새로운 이미지나 프레임워크를 추가하지 않았다. 4번 행사 포스터·사인과의 정합성은 해당 자료가 확정되면 맞춘다. 자세한 적용과 검증은 [최종 인수인계](FRONTEND_FINAL.md)를 참고한다.
