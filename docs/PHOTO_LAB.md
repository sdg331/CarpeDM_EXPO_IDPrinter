# 사진 프레이밍·로컬 CV 시험

기존 `/` 키오스크와 별도인 `/static/photo-lab.html`에서 시험한다. 캐릭터 매칭·NFC·발급·인쇄·퇴근 사진 정책을 교체하지 않는다. 사용자 실제 사진이나 새 캐릭터 원본을 GitHub에 포함하지 않는다. 예시 버튼은 저장소에 이미 있는 작은 `char_01.png`에 브라우저에서 시험용 여백을 더한다. 원본이 작은 캐릭터의 표시용 예시이며 실제 방문자 사진의 품질 검증 자료가 아니다. 기존 품질 기준을 낮추지 않는다.

## 1. 브라우저 프레이밍만 빠르게 시험

Node.js 20 이상에서 별도 설치·API 키 없이 실행한다.

```sh
npm start
```

<http://localhost:4173/static/photo-lab.html>에서 사진 선택 또는 기존 캐릭터로 시험한다. 슬라이더로 확대·좌우·상하를 조절하고 720×960 PNG로 저장할 수 있다. 이 단계는 서버에 사진을 보내지 않는다. 정적 서버에서는 배경 처리 버튼이 비활성이고 실제 생성 결과를 꾸며 표시하지 않는다.

## 2. 로컬 배경·구도 정리까지 시험

Python 3.12 환경과 기존 로컬 YuNet/SFace 모델이 필요하다. 이미 준비된 `.venv`와 `models`가 있다면 설치·다운로드를 반복할 필요 없다. 사진 실험에는 외부 AI API 키가 필요 없다.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
bash scripts/fetch_models.sh
KIOSK_PHOTO_LAB=1 KIOSK_NFC=disabled KIOSK_PRINT=screen .venv/bin/python scripts/run_kiosk.py --port 8014
```

<http://127.0.0.1:8014/static/photo-lab.html>에 접속한다. 사용 중인 포트의 서버를 종료하지 말고 다른 빈 포트를 선택한다. `.env`에 실제 NFC/인쇄 설정이 있어도 위 실행은 실험용으로 사용하며 이 페이지에서 장치 API를 호출하지 않는다. 서버 실행기는 접근 로그를 끈다. 실험을 마친 서버를 종료하면 실험 opt-in도 끝난다.

1. 본인 또는 사용에 동의한 사진 한 장을 선택한다.
2. 한 사람이 정면에서 밝게 찍힌 사진을 사용하고, 얼굴과 어깨가 잘리지 않게 위치를 조절한다.
3. `로컬 배경·구도 정리`를 누르면 현재 프레이밍 PNG 한 장을 같은 출처의 **로컬 서버**로 보낸다.
4. YuNet 얼굴 위치 → 균일 확대/3:4 자르기 → GrabCut 배경 분리 → 로컬 배경 합성을 수행한다. 새 얼굴·정장·머리카락·몸을 생성하거나 피부를 미화하지 않는다.
5. 오른쪽 결과를 비교한다. 중앙 얼굴·실제 옷은 기존 CV의 보호 영역을 유지하지만 경계·머리카락·복잡한 배경에는 분리 오류가 있을 수 있다. 얼굴 없음·여러 사람·기울기·화질 오류는 결과 대신 다시 촬영할 안내를 표시한다.
6. 결과가 적절할 때만 직접 PNG 저장을 누른다. 출력·카드 등록과 연결하지 않는다.

브라우저가 읽을 수 있는 JPEG/PNG/WebP만 받는다. 최대 8 MiB·1,200만 픽셀이며 헤더 크기를 확인하고 브라우저/서버의 전체 디코딩 전에 큰 압축 이미지를 거부한다. HEIC는 JPEG로 변환한다. 원본은 브라우저 메모리에, 배경 처리 요청과 결과는 로컬 서버의 처리 메모리에만 존재한다. 별도 ProfileStore·SQLite·임시 파일에 저장하지 않는다. 취소·재촬영·새 사진·페이지 종료에서 오래된 응답을 무시하고 카메라 트랙·Blob URL·이미지 참조를 정리한다. 사용자 PNG 저장은 명시적으로 누른 경우에만 수행한다. 이 설명은 RAM의 즉시 물리적 삭제를 보증한다는 뜻은 아니다.

## 모바일과 카메라

`사진 선택`은 갤러리, `휴대폰으로 촬영`은 지원 기기에서 운영체제 카메라 선택을 요청한다. 브라우저에 따라 파일 선택 창으로 열릴 수 있다. 카메라 켜기는 localhost 또는 HTTPS 보안 문맥과 카메라 권한이 필요하다. 권한 거부·미지원·촬영 취소 시 파일 선택으로 시험할 수 있다. 미리보기는 촬영 버튼을 누르기 전에는 사진을 보내지 않는다.

모바일 viewport/터치와 합성 카메라 스트림을 검증하되 실제 iOS/Android 카메라·HEIC 변환·권한 UX 검증을 대신하지 않는다. 휴대폰의 localhost는 휴대폰 자신을 가리킨다. 기존 API의 loopback 제한 때문에 LAN에서 Mac의 배경 API를 직접 사용할 수 없다. 이를 풀거나 운영 서버를 공개 배포하지 않는다. 실제 휴대폰은 우선 파일/촬영 선택·브라우저 프레이밍을 시험하고, 서버 배경 정리는 서버를 실행한 기기에서 시험한다.

## 정장 생성: 미구현

현재 결과는 원래 옷이다. 정장 템플릿 오버레이도 연결하지 않았으며 성공한 것처럼 표시하지 않는다. 후속 실제 생성은 별도 결정이 필요하다.

- 얼굴 보존 방법과 합성 방식: 로컬 정장 참조 자산/템플릿 또는 생성 제공자 선정.
- 제공자별 요금·호출 상한·비용 부담자: 미선정, 비용 미정. 현재 로컬 예시는 외부 생성 호출을 하지 않는다.
- 방문자 사진의 외부 전송 여부, 처리 지역·보관·삭제 정책, 권리와 사전 동의 문구: 미결정. 선택·촬영은 외부 AI 전송 동의가 아니다.
- 새 API 키 생성·설정, 외부 서비스 사진 업로드: 이 작업에서는 실행하지 않는다.
