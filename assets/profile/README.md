# Profile reference assets

The live Mode B pipeline now preserves the visitor's original face, neck, and
clothing. It only normalizes the close-up framing and separates the background.
It does not load a suit template. The home screen uses the original
`assets/characters/char_01.png` as its labelled example.

`suit_photo.png` is the unchanged 1254×1254 RGBA photograph supplied by the user
on 2026-09-22. No ownership or license is inferred from the upload.
`suit_neutral.png`, `scripts/make_profile_asset.py`, and `example_portrait.png`
remain historical reference assets; none is used by the current portrait flow.
